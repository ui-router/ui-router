Notes from when I added Angular 11 support

- in uirouter/angular:
 - update peer deps for angular packages, bumping each range by one
 - update angular packages manually to the lower range supported (for angular 11, set to ^10.0.0)
 - update ng-packagr manually to the lower range supported (for angular 11, set to ^10.0.0)
 - update typescript to the version required by @angular/compiler-cli
 - npm exec -- check-peer-dependencies
 - gh pr create
 - update other libs
 - update tests in ../integration-tests/angular-versions/
   - (cd ../integration-tests/angular-versions && ./scaffold.sh 11)
   - remove old tests from ../integration-tests/angular-versions and downstream_projects.json
 - update tests in ../integration-tests/typescript-versions/
   - (cd ../integration-tests/typescript-versions && ./scaffold.sh 4.5)
   - (maybe) remove old tests from ../integration-tests/typescript-versions and downstream_projects.json
 - npm exec -- check-peer-dependencies
 - gh pr create
 - npm run release
